# Отчёт по лабораторной работе

## Задание

Модифицировать программу из л/р №1 для параллельной работы по технологии CUDA. Провести эксперименты с разными размерами матриц и различными конфигурациями сетки блоков.

---

## Ход работы

В ходе работы код с 1 лабораторной работы был адаптирован код с 1 ЛР для работы с технологией OpenCL, так как на ноутбуке, где выполнялась программа, имеет встроенный Intel UHD Graphics, но нет NVIDIA. Были проведены тесты для различного числа потоков процессора.

## Итоги
1. Оптимальный размер блока зависит от размера матрицы. Для интегрированной графики Intel с max_work_group_size = 512 при решении больших задач (≥800) предпочтительны маленькие квадратные блоки (8x8), а не максимально возможные.
2. Для малых матриц (≤400) выигрывают большие блоки (32x16) за счёт уменьшения накладных расходов на запуск ядра.
3. Cишком большие рабочие группы могут ухудшать производительность из-за конфликтов в кэше и ограничений пропускной способности памяти, особенно на встроенных GPU без выделенной видеопамяти.
4. Маленькие блоки (8x8) продемонстрировали лучший результат среди остальных, так как лучше используют локальность данных и реже требуют повторной загрузки.
