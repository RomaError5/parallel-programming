**Задание на лабораторную работу 1**

Написать программу на языке C/C++ для перемножения двух квадратных матриц.

Исходные данные: файл(ы), содержащие значения исходных матриц.  
Выходные данные: файл со значениями результирующей матрицы, время выполнения, объём задачи.  
Обязательна автоматизированная верификация результатов вычислений с помощью сторонних библиотек или стороннего ПО (например, на Matlab/Python).

---

## Ход работы

В ходе лабораторной работы были сгенерированы две квадратные матрицы размером 100×100 элементов при помощи модуля `generate_matrix.py`; были получены матрицы `A` и `B` .

После генерации матриц при помощи модуля `matrix_multiply.cpp` было выполнено умножение матриц `A` и `B`, в результате чего получена новая матрица `C`.
Время выполнения функции `multiplyMatrices(...)` составило:  
`Время выполнения: 0.001037 секунд` 

Количество операций для умножения матриц составило:  
`Количество арифметических операций: 1990000 (умножений: 1000000, сложений: 990000)` 

Для верификации результатов использовался модуль `verify.py`. По итогам его работы были получены результаты, приведённые на рисунке 2.
