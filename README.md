# Отчёт по лабораторной работе

## Задание

Параллельную версию программы на MPI необходимо также запустить на суперкомпьютере «Сергей Королёв».

---

## Ход работы
Для работы на суперкомпьютере и снижения количества действий код программы из 3 ЛР была изменена: генерация матриц была добавлена прямо в .cpp файл, удалены операции сохранения в файлы, был оставлен вывод результатов в терминал. Исходные файлы загружаются на кластер, после чего программа компилируется:

`mpicxx Program.cpp -o lab5`

Запуск в очередь производится через сформированный `.pbs` файл.

---

## Итоги
В ходе выполнения лабораторной работы MPI-программа была успешно запущена на суперкомпьютере «Сергей Королев». Проведены эксперименты с разным количеством процессов и размерами матриц. Результаты показали, что MPI демонстрирует высокую масштабируемость - увеличение числа процессов приводит к росту производительности. Также при сравнении с результатами на локальном компьютере из 3 ЛР (работающий на процессоре 12th Gen Intel(R) Core(TM) i5-1235U) можно увидеть, что суперкомпьютер эффективнее выполняет перемножение матриц на MPI.
